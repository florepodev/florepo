{% call card('Authentication') %}

Create an API token under API tokens (or via POST /api/v1/tokens). It can be used as:

  • Authorization: Bearer flo_… – REST API and npm (_authToken)
  • HTTP Basic password – docker login, pip, twine (username = your user)

Tokens inherit the permissions of their user: reader may read, deployer may publish to all or only to selected hosted repositories, admin may do everything incl. reports and settings. Public repositories can be read anonymously. Errors are returned as {"error": "…"}.

List endpoints accept sort/dir and paginated ones page/per_page; the response contains items, total and pages.
