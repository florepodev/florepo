Authentication

Local accounts always work (e.g. the bootstrap admin). With LDAP enabled, users that have no local account sign in with their directory credentials – in the web UI, with docker login and with package managers (HTTP Basic). Their role and write permissions follow the group mapping below. API tokens work for both kinds of accounts.
